# 0001: Keep code and evidence in the level folders

Date: 2026-11-08. Status: accepted. Decided by: Jesun Ahmad Ushno.

## Context

The portfolio standard v2 suggests src/ for code, experiments/ for raw
evidence and results/ for scored results. In this repo each level
folder (level-1-learn, level-2-build, level-3-deep) holds one
self-contained implementation, its runner, its scripted plan and the
results file the runner writes. The tests, the CI reproduction check,
the dashboard build (site/src/App.jsx, site/src/guard.check.mjs) and
the Pages path filter all address those files by path, and the level
READMEs, release notes and fan-out drafts cite them.

## Decision

Keep the three level folders as the code and evidence locations and
list them in the README layout table, as the standard allows for
domain-named folders. No src/, experiments/ or results/ folder is
added. Each results file is regenerated by its runner and checked byte
for byte in CI.

## Consequences

Every existing link and citation keeps working. The cost is that code
and evidence share a folder, so the append-only rule for evidence is
enforced by the CI byte-for-byte check rather than by folder. A future
confirmatory cycle with new, dated evidence can add experiments/ then.
